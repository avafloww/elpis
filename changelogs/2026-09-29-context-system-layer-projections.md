# Typed system-layer shadow projections

The dark context-graph recorder now receives the exact frozen fragments used to build each legacy system message. Schema v33 stores those fragments as immutable content-addressed private projections, and V3 shadow plans reference only their IDs with explicit scope/blocker lineage.

The provider request, active monocontext loop, compaction, coordinator, effects, and graph activation are unchanged. Current layers remain deliberately ineligible: the operating contract, memory, focus, identity candidate, reasoning hint, unlineaged history, and effect tools are not yet branch-authorized. A graph-only materializer accepts only explicitly scoped contract, integrated-self, and same-world policy records and fails closed on legacy, private, missing, reordered, or generation-mismatched layers.

Focused projection, store, migration, privacy, and Agent request-seam regressions were added. After deployment, verify schema 33, dark activation, disabled shadow mode, empty projection tables before natural traffic, and no coordinator/head movement.
