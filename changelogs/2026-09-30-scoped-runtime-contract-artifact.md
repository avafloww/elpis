# Scoped runtime contract source artifact

Schema 42 now seeds one immutable, content-addressed runtime-contract artifact for future scoped context branches. The contract is newly authored rather than relabeled from the legacy mixed prompt, is explicitly tool-free, and does not import legacy memory, focus, people records, dynamic cards, or host capabilities.

The migration checksum follows the exact artifact identity, and the graph store rejects missing or changed bytes. This stage grants no approval, profile, provider, tool, effect, activation, or live runtime authority; it only establishes durable source evidence for a later explicit authorization step.

Validation covers exact migration history, immutable and `INSERT OR REPLACE`-safe storage, typed drift rejection, a boundary check showing supplied legacy canaries do not enter the independent artifact source, failed-mutation lifecycle stability, the deterministic unit suite, build, and benchmark static checks.
