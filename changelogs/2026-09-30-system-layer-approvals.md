# Dormant system-layer approvals

Schema 37 adds an immutable approval-receipt boundary for typed system-layer projections. A receipt must bind one exact stored layer and source hash to a matching semantic role and provenance basis. Database guards reject legacy-mixed, identity-candidate, private-root, wrong-kind, wrong-scope, wrong-world, and source-hash-substituted layers.

The migration creates no approvals. There is no writer, system profile, Agent or provider integration, assembler binding, tool or effect authority, activation change, or continuation-head change. Generic system-layer projections remain unauthoritative until a later profile stage consumes explicit approvals.
